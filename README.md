# TU Wien Raumplanung Reihungstest 2026 — Study Dashboard

Interactive exam preparation for the Bachelor Raumplanung und Raumordnung entrance exam at TU Wien.

**Live site:** https://johngavin.github.io/urban_planning/

## What is this?

A self-contained study dashboard built as plain HTML/CSS/JavaScript — no installation needed. Open `site/index.html` in any browser.

Features:
- Bilingual knowledge base (German + English) covering all exam material
- Interactive multiple-choice quizzes with instant scoring
- Countdown timer to exam day (10 July 2026)
- 10-week study plan with milestones
- Student progress dashboard (stored locally in your browser)
- Exam day details and preparation checklist

## Exam Details

| Detail | Value |
|--------|-------|
| Exam date | **10 July 2026** |
| Duration | 2 hours |
| Format | Written on paper (MC answer sheets) |
| Language | German only |
| Parts | A: Subject Knowledge (40%) • B: Text Comprehension (20%) • C: Cognitive Abilities (40%) |
| Places | 200 per year |
