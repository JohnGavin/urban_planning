# Student Quick Start Guide

You want to prepare for the TU Wien Raumplanung entrance exam. You have Claude Cowork (the Claude desktop app). You don't need a GitHub account, programming skills, or any technical tools.

## What You Get

| Feature | Description |
|---------|-------------|
| Study material | Complete knowledge base of all exam topics (German + English) |
| Interactive quizzes | 76 multiple-choice questions with exam-style scoring |
| Progress tracking | Dashboard showing your scores, weak areas, and history |
| Exam countdown | Days until the exam, study plan, exam day checklist |
| Cube (Würfel) practice | 16 spatial reasoning questions (hardest part of the exam) |
| Mock exam | Full practice test combining all question types |

## Step-by-Step Setup

### Step 1: Open Claude Cowork

Open the Claude desktop app (Claude Cowork) on your computer.

### Step 2: Give Claude this prompt

Copy and paste this ENTIRE block into Claude Cowork:

---

**Prompt to paste:**

```
I want to prepare for the TU Wien Raumplanung entrance exam (Reihungstest).
There is a ready-made study dashboard at https://github.com/JohnGavin/urban_planning

Please:
1. Download/clone that repository to my computer
2. Open the website (site/index.html) in my browser
3. Explain what I should do first

I am not a developer — please handle all technical steps for me.
I just want to study and take practice quizzes.
```

---

Claude will:
- Download the entire project to your computer
- Open the study dashboard in your browser
- Show you where to start

### Step 3: Start studying

The home page shows a "Start Here" section that tells you what to do next. Follow the 8-step study path.

## What You Can Ask Claude to Do

Here are things you can ask Claude Cowork at any time:

| What you want | What to say to Claude |
|---------------|----------------------|
| **Start studying** | "Open the study dashboard and tell me what to do next" |
| **Take a quiz** | "Open the OEREK principles quiz in my browser" |

## If Something Doesn't Work

| Problem | What to tell Claude |
|---------|---------------------|
| Page looks broken | "The page at [URL] doesn't look right — can you fix it?" |
| Quiz won't load | "The quiz isn't loading questions — check data/questions.json" |
| Want to start over | "Reset everything and re-download from GitHub" |
| Need offline access | "Make sure everything works without internet" (it already does, except cloud sync) |

## You Do NOT Need

- A GitHub account
- Programming knowledge
- Node.js, Python, R, or any other tools
- A terminal or command line
- To understand HTML, CSS, or JavaScript

Claude Cowork handles all of that for you. You just study and take quizzes.

## Exam Key Facts

| Detail | Value |
|--------|-------|
| Date | **10 July 2026** |
| Duration | 2 hours |
| Format | Paper, multiple choice (tick answers on answer sheet) |
| Language | German only |
| Parts | A: Subject Knowledge (40%) + B: Text Comprehension (20%) + C: Cognitive Abilities (40%) |
| Places | 200 per year |
| Registration | [TISS Portal](https://tiss.tuwien.ac.at/aufnahme/aufnahmeverfahren) — deadline 4 May 2026 |
| Recent acceptance | ~82-91% of participants get a place |

## Study Priority

1. **OEREK 2030** — the biggest and most important topic (40% of exam)
2. **Cognitive skills** — practice daily: analogies, number sequences, logic, Würfel (40% of exam)
3. **Studienplan** — what IS Raumplanung, programme structure
4. **Text comprehension** — practice with sample texts (20% of exam)
