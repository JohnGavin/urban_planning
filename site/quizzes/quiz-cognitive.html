Quiz: Cognitive Skills

Part C — Kognitive Fähigkeiten (40% der Gesamtpunktzahl)

Coming Soon. Practice for Part C of the Reihungstest — cognitive abilities including analogies, number sequences, logical deduction, spatial reasoning, and matrix pattern recognition. This section is worth 40% of the total score.
What Part C Tests
Task TypeDescription
Analogies (Analogien)A is to B as C is to ? — verbal and conceptual relationships
Number Sequences (Zahlenreihen)Identify the pattern and find the next number
Logical Deduction (Schlussfolgern)If-then reasoning, syllogisms, logical conclusions
Spatial Reasoning (Räumliches Denken)2D to 3D folding, rotations, mirror images
Matrix Patterns (Matrizenaufgaben)Identify the missing piece in a visual pattern matrix
Text Comprehension (Part B)Read German spatial planning texts — true/false/not determinable
Practice Strategy

Cognitive skills improve with timed practice. The exam allocates a fixed time per section — speed and accuracy both matter. Focus especially on the question types you find hardest.

Tip: The exam uses German throughout. Even cognitive tasks have German instructions — reading speed in German matters.
